# Titanic Survival Prediction

This project predicts whether a passenger survived the Titanic disaster using Machine Learning. The dataset was cleaned by handling missing values and converting categorical data into numerical form. A Random Forest Classifier was trained and achieved an accuracy of 82.68%.

An interactive user interface was also developed using ipywidgets, allowing users to enter passenger details and receive real-time survival predictions.

## Features

* Data Cleaning and Preprocessing
* Feature Engineering
* Random Forest Classification
* Survival Prediction
* Interactive UI using ipywidgets

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* ipywidgets
* Kaggle Notebook

## Model Performance

* Algorithm: Random Forest Classifier
* Accuracy: 82.68%
